# `/architect`

Keep system architecture and data-flow diagrams synced with the codebase.

Scans the codebase and writes two Mermaid diagrams — system architecture and data flow — into a dedicated section at the bottom of the repo's `README.md`, marked with `<!-- architecture-start -->` / `<!-- architecture-end -->`. Re-running updates them in place instead of leaving stale diagrams behind.

See [`SKILL.md`](SKILL.md) for the full instructions.
