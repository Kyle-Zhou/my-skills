# `/e2e`

Deliver a feature end-to-end: design, review, plan, implement, test, review.

Takes requirements through the full delivery cycle — a design doc, parallel subagent review, orchestrator triage of that feedback, a finalized plan (with `/diagram-plan` diagrams), implementation, a conservative set of E2E/integration tests around the happy path and key failure points, and a final review (`/code-review` if available, otherwise a review subagent). For non-trivial features, not quick fixes.

See [`SKILL.md`](SKILL.md) for the full instructions.
