# `/diff-viewer`

Review uncommitted changes side-by-side in a local browser UI.

Starts a local, zero-dependency web server showing old vs. new — red/green highlights, light/dark toggle — with a collapsible file-tree sidebar split into Staged Changes and Changes, like an IDE's source control panel. Opens automatically in your default browser, binds to `127.0.0.1` only, and runs one instance per repo — launching it again replaces the previous instance instead of stacking up background processes.
